A responsive restaurant website created using **HTML5** and **Tailwind CSS** as part of my **Tailwind CSS Daily Task - Day 4**.

This project is inspired by the **Covai Anganan Biriyani** website and focuses on building a modern restaurant landing page with responsive layouts, food sections, images, videos, navigation, and footer design.

## 🚀 Features

* Responsive navigation bar
* Mobile hamburger menu
* Hero section with text overlay
* Food category cards
* About / Food information sections
* Responsive grid layouts
* Gradient backgrounds
* Hover effects and transitions
* Swiggy and Zomato sections
* Food video gallery
* Customer review section
* Restaurant contact information
* Responsive footer
* Mobile, tablet, and desktop support

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* Tailwind CSS CDN
* Google Fonts
* Responsive Web Design

## 📱 Responsive Design

The website is designed using Tailwind CSS responsive breakpoints such as:

* `sm`
* `md`
* `lg`

The layout automatically adjusts based on the device screen size.

## 🖼️ Output

The final website contains multiple responsive sections showcasing the restaurant, food categories, biriyani specials, traditional dishes, videos, customer reviews, and contact information.

Screenshots of the completed webpage are available inside the **`output_screenshot`** folder.

## 💻 How to Run

1. Clone or download this repository.
2. Open the `DAY_4_TAILWIND_TASK_4` folder.
3. Open `index.html` in any modern web browser.
4. No additional installation is required because Tailwind CSS is loaded through CDN.
